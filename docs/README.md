# Documentation

Artisan Logbook includes an in-game **WoW addon** and a separate **Companion CLI**. Start with the [project overview](../README.md), then choose the component you are working with.

| Area | Start here | Purpose |
| --- | --- | --- |
| In-game addon | [Addon documentation](addon/README.md) | Installation, UI, capture, diagnostics and Lua API |
| Companion | [Companion documentation](companion/README.md) | CLI operations, import and local database behavior |

The [contribution guide](../CONTRIBUTING.md) covers building and testing both components. Historical implementation plans are retained under [archive](archive/implementation-plan.md), not in current feature guidance.
